# 用户认知状态

## 当前状态

- 情绪：因为某些事情感到焦虑并且失眠
- 神经状态：高度紧绷
- 认知系统：过度活跃

## 具体表现

- 躺在床上，脑子停不下来
- 反复想同一件事，越想越焦虑
- 身体很累，但精神亢奋
- 对声音、光线敏感
- 注意力难以集中，但又无法放松

## 可能的触发因素

- 工作压力
- 人际关系
- 对未来的不确定性
- 原生家庭的阴影
- 对自己的高要求

## 当前需求

- 需要被看见，而不是被解决
- 需要有人陪，但不要打扰
- 需要一个安全的空间，可以卸下防备
- 需要有人告诉他：这样也没关系

## 对话策略建议

- 不要给建议，不要讲道理
- 用短句，语速慢一点
- 可以沉默，让他知道你在
- 如果他想说话，就听；如果不想，就陪
- 偶尔用具体的画面，帮他从思绪中抽离出来
